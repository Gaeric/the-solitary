# 术式独立触发：来源与联动迁移

## 当前状态

新增独立入口 `TheSolitary.ArtEffects.ArtTrigger.Trigger` / `TriggerRandom`。
八处来源已切换到独立入口，保留各自原有次数和升级判定，中英描述同步更新。
旧 Cards.Arts 生成/自动打出工具已删除；五张 Token 类型暂保留兼容旧存档与资源，
当前来源均不再创建它们。用户的 character.org 不修改。

新入口不创建 CardModel、不操作牌堆、不触发生成牌、打牌、消耗或充能球事件。
伤害使用 `ValueProp.Unpowered`，`dealer` / `cardSource` / `cardPlay` 全部为 null。
负面效果同样没有 applier / cardSource，先伤害后施加；致死不再施加。
普通伤害事件和目标受伤结算仍会正常执行；“无来源”不意味着绕过游戏伤害管线。
不受力量、卡牌附魔、卡牌重放或充能球集中加成；不自动推进缓慢的打牌计数。
术式自身的伤害规则为：基础伤害 + 当前目标身上的可见负面效果种类数（同种多层只计一次）。
每次伤害前重新统计，包含回想的额外结算；本次伤害后施加的负面效果只影响后续伤害。
该规则默认生效，不需要新增能力或 Buff，伤害来源与 `Unpowered` 保持不变。

默认随机选敌，支持显式指定可命中敌人；无敌人不结算并返回 null。
随机术式保留旧规则：所有可命中敌人都有缓慢时，排除凋零。
ArtTrackerPower 现在统一记录实际触发次数，在每次结算伤害前 +1。
通过 IArtTriggerListener.AfterArtTriggered 通知直接联动，带归属、种类、升级状态和目标。
监听者从战斗有效模型列表中快照，包含 Power、未熔毁遗物和战斗牌堆内的牌；按归属过滤。
致死的该次触发也发送通知，后续无目标则停止。
术式回想每层额外结算一次同类型、同升级状态的术式；不递归扩大，不重抽种类。
额外结算计入次数，种类不重复计入；原目标死亡后重新选敌，无敌人则不再结算。

## 悬停说明

术式相关卡牌、能力与遗物通过 `ArtHoverTips.Create` 共用两块文本提示：规则与五种术式速查。
速查伤害与负面层数读取 `ArtDefinition`；名称复用既有中英术式名与原版负面效果名，不创建卡牌模型。
随来源升级的术式显示对应数值；能元妙术与全知形态始终显示术式+；纯联动来源显示普通 / 升级对照。
提示只展示基础伤害，不假定随机目标的负面种类数。仍需游戏内检查提示换行、布局与升级预览。

## 特效

复用游戏 `res://scenes/vfx/vfx_attack_lightning.tscn`，不复制充能球逻辑。
纹理先去除原黄色，再按术式颜色染色；普通缩放 1.0，升级缩放 1.35。
同种普通与升级版颜色相同，只以缩放区分；颜色和倍率为首版可调参数。
保留原版动画的约 0.33 秒自动释放，使用原闪电激发音效。
无额外逐次等待；TestMode / NonInteractiveMode 跳过表现。
仍需游戏内检查颜色区分、连续触发节奏和不同敌人体型下的视觉效果。

## 已迁移

### 术式来源

- 匣中术 ArtOfTheBox：加入手牌 → 触发，保留升级参数。
- 掌中奇术 ArtOfThePalm：同上，独立评估其自身减费机制。
- 混叠 Aliasing：同上，另保留原卡的附魔效果。
- 能元妙术 ArtOfTheSource / Power：回合开始生成术式+ → 触发术式+。
- 路径追踪 PathTracing：逐张自动打出 → 逐次触发。
- 挖掘 EnchantDig：抽到附魔牌后自动打出 → 触发。
- 全知形态 ArcaneReturn / Power：附魔牌打出后触发术式+，复核并移除不再需要的卡牌递归守卫。
- 来回往复 BackAndForth（遗物）：洗牌生成术式 → 触发。

### 直接监听术式的效果

- 余弦 Cosine / Power：生成牌钩子 → 专用术式触发通知。
- 焦散 Caustic：生成术式减费 → 触发术式减费。
- 术式回想 SpellRecall / Power：所有术式效果额外触发一次，每层多一次，不使用 Replay。
- 奇点爆破 SingularityBurst / ArtTrackerPower：生成数 → 触发数，统一统计时机。
- 凝术御甲 ArcaneAegis（遗物）：打出术式获得格挡 → 术式触发联动。
- 术元交感 ArcaneSympathy（遗物）：每触发4次为手牌随机附魔，保持原阈值。
- 四象之阵 FourSymbolsFormation（遗物）：按 CardModel 类型识别 → 按 ArtKind 识别。

### 四张能力牌重设计（已实施）

- 凝华 EnchantAscension：金能力，1→0费；打出后每层在战后提供一次牌组随机永久附魔奖励，参考禁忌魔典奖励流程。
  使用 RitsuLib ModCustomReward 注册恢复工厂；选择未附魔且随机池可附魔的牌，不覆盖旧附魔。
  取消选牌保留奖励，无可用牌时可正常领取完成；选牌由原版同步，随机数用玩家 Rewards RNG。
- 万物通元 EnchantedCreation：金能力，2费，升级固有；每触发5次术式，所有手牌数值型附魔+1，仅本场战斗。
  明确传 persistToDeckVersion:false，不改变牌组原件；无附魔或非数值型附魔不变。
- 维度调和 DimensionalHarmony：蓝能力，2→1费；生成牌随机附魔，已有附魔不覆盖，重复打出不叠加。
- 术元编织 ArcaneWeaving：蓝能力，2→1费；每触发5次术式，生成一张随机无色牌加入手牌。
  按原版 Largesse 过滤解锁/多人/可战斗生成牌；保留生成牌钩子，可触发维度调和。
- 万物通元、术元编织各副本使用 Instanced Power 独立计数，从打出后开始，进度跨回合保留。
  包含回想额外触发，不追溯打出前次数；状态角标和悬停提示显示剩余次数。

### 间接受影响，后续回归检查

元能吸附 EnergyAbsorption、滤波 Filter、光栅 Raster、辐照 Irradiation、元能核心 ArcaneCore、
抽样 Sampling，以及其它按附魔/打牌/攻击次数结算的效果。
它们不应因术式触发而收到伪造的卡牌事件，但仍应响应真正打出的主体卡牌。
旧 Cards.Arts 已删除，中英描述已更新；五张旧 Token 暂留兼容，不再有生成来源。
